# APOLLO visual system

The frontend is an operational booking interface for a fictional local demo.

- Warm light background (#f5f8f6), white content surfaces, deep teal text (#173a43).
- Primary actions use teal (#0e6b64); success is stated in text as well as color.
- DM Sans for navigation, forms, and data; Instrument Serif for large page headings.
- Maximum page width: 1240px. Desktop booking pairs a progress column with the task panel.
- Mobile stacks the task and progress; navigation remains horizontally scrollable.
- Radii: 10–16px for controls and panels. Only compact system indicators use pills.
- Backend status labels distinguish model files, loaded models, reachability, and RAG validation.
- All controls have visible keyboard focus; reduced-motion preferences are respected.
- Browser API errors, empty doctor/slot lists, safety escalation, and citation failures have explicit states.
- Appointment and policy details are backend data, never decorative sample content.
